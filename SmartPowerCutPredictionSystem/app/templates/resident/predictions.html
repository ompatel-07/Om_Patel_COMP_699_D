Prediction Process

How Prediction Information Is Generated

📋

Complaint Data

The system builds the complaint dataset using administrator-uploaded sample records together with complaints submitted by residents.

⚙

Data Preparation

Available complaint records are prepared and divided into training and testing data before model evaluation.

🔄

Random Forest

The Random Forest model is trained using the training data and evaluated against the testing data.

📊

Prediction Result

The trained model is used to identify possible power cut patterns for available complaint information.

Data Updates

Prediction Model Updates

i

As new complaint information becomes available, the system can use the expanded complaint dataset for future model training and analysis. Prediction results are stored for future reference and analysis.
